Simplicial SMOTE

SMOTE generates points along k-NN edges; Simplicial SMOTE generates points inside a simplex using barycentric coordinates. Choose a dataset and oversample budget, then start the demo.

Demo scenario

Compare oversampling, then evaluate on test data

  1. Generate samples Oversample with k = 5, p = 3, seed = 2207 using the budget below (fraction of m = n⁻ − n⁺ or a custom count).
  2. Train Fit LogisticRegression(C=1.2) on the augmented training set.
  3. Results Evaluate on the test set: recall, precision, F1, FN, FP, plus the decision boundary.
  4. Compare Original, Random, Global (Mixup), SMOTE, and Simplicial SMOTE.

n⁺ = minority · n⁻ = majority · m = n⁻ − n⁺ full balance target.
